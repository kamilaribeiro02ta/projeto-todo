# CineCRUD — Sistema de Filmes

Atividade desenvolvida por **Melissa e Bonfim**.

## Funcionalidades

- Página de cadastro de filmes
- Botão para apagar filmes
- Página de edição de filmes
- Listagem de filmes
- Busca por título
- Persistência com LocalStorage
- Layout responsivo

## Como executar

Abra o arquivo `index.html` no navegador ou publique o repositório na Vercel.
